# /devkit:address-pr:help — verbose flag reference

Equivalent to `/devkit:address-pr --help` (or `-h`, or `?` as a standalone token).

## Execute

1. Locate the help reference at `<plugin-root>/references/help/address-pr.md`.
2. Read it.
3. Print the **"Verbose flag reference"** section verbatim. Includes `--dry-run`, `--ignore-bots`, `--reviewer=<login>`, `--auto-resolve`.
4. STOP. The user reads, then re-invokes with concrete args.

## Guardrails

- Read-only. Never modifies files.
